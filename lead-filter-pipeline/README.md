# Lead Filtering Pipeline (Telethon + Asyncio + AI Verifier)

Трехступенчатый модуль отбора и фильтрации входящих заявок в Telegram:

1. `dedup.py` - нормализация текста, SHA-256 и нечеткая кросс-чат дедупликация по шинглам (Jaccard), отсев спамеров и биржевых репостов.
2. `classifier.py` - ролевой классификатор сообщений (`BUYER_HOT` против HR-вакансий, рекламы и офферов исполнителей) с настраиваемыми правилами под разные ниши.
3. `ai_verifier.py` - асинхронная проверка неоднозначных сообщений через LLM с кэшированием результатов.
4. `tg_client.py` - кеширование `InputPeerChannel` (`resolve_peer_cached`) без лишних `ResolveUsernameRequest`, файловый lock сессии и соблюдение лимитов `FloodWait`.
