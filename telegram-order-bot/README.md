# ClientFlow Demo Bot (`aiogram 3.x` + `sqlite3`)

Эталонный демонстрационный Telegram-бот для показа клиентам под ключ. Покрывает все ключевые сценарии, которые чаще всего заказывают в коммерческой разработке.

## Возможности
- **Главное меню с inline-кнопками:** навигация без лишних сообщений, редактирование карточек на месте.
- **Интерактивный калькулятор стоимости:** переключатели модулей (*Админка, Оплата, Google Sheets / API, База клиентов, Срочный запуск*) с мгновенным пересчётом бюджета и срока.
- **Оформление заявки (FSM в 3 шага):** сбор имени, контакта (или автоподстановка `@username` в один клик) и описания задачи с валидацией и переносом расчёта из калькулятора.
- **Мои заявки:** просмотр истории обращений и статусов в реальном времени.
- **Админ-режим (Демо-переключатель):** статистика по воронке, смена статуса заявки по клику (`Новая → В работе → Готово`), выгрузка всех заявок в **CSV** (UTF-8 с BOM для Excel/Google Sheets).

## Запуск за 1 минуту

```bash
# 1. Перейдите в папку бота
cd demo_bot

# 2. Установите зависимости
py -3 -m pip install -r requirements.txt

# 3. Создайте .env из примера и вставьте токен от @BotFather
copy .env.example .env

# 4. Запустите бота
py -3 bot.py
```

## Запуск автотестов

```bash
py -3 -m pytest -v
```

## Структура проекта
- `bot.py` — точка входа, инициализация БД и `Dispatcher`.
- `config.py` — загрузка `.env` и настроек (`Settings`).
- `calculator.py` — логика расчёта стоимости, сроков и форматирования карточек.
- `db.py` — работа с `sqlite3`, валидация данных и экспорт CSV.
- `keyboards.py` — inline-клавиатуры (`InlineKeyboardBuilder`).
- `handlers/client.py` — клиентские сценарии, калькулятор и 3-шаговый FSM.
- `handlers/admin.py` — демо-админка, статистика, смена статусов и экспорт CSV.
- `tests/test_bot_core.py` — unit-тесты на `pytest`.
